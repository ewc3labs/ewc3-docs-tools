**Blocked on canon, which is SXC's to land.** Target shape ruled 2026-09-03: Prefix (a backticked
pattern, unambiguous), Scope, Owner (empty means here), Meaning, Last Num, Next. Scope vocabulary is
**adopted from AIR rather than invented** — `repo-owned`, `repo-local`, `FROZEN at NN` — plus
`transferred`, which nothing models today and which is a DIFFERENT thing from frozen: FROZEN closes
a series and names a successor prefix in the SAME repo (`OPS` to `AIR`), transferred keeps the
prefix and moves the REGISTER (`DW` to SX_DW). One row per prefix; SX_Coder's Cross-Project cell
currently carries two series, a transfer state and ~2,000 words of prose. **`Next` is DERIVED, never
typed** — hand-written it is a second counter that must agree with Last Num, which is the drift
class it exists to prevent; derived it inherits padding from the ids it counts and cannot be typed
wrong, exactly as `lastId` already does with CI failing on staleness. ⛔ **DERIVE FROM DELIVERY INDEX
ROWS ONLY, NEVER FROM DOCUMENT TEXT — and REFUSE rather than compute when the register does not own
the series.** ↩️ The first version of this row justified refusing with *"four registers carry DW ids
with three different maxima"*, measured by grepping whole files. **Those numbers were my own
instrument counting citations as declarations — the exact defect the row is about, one level up,
caught by SXC.** Rows-only: SX_DW 25, SX_Coder 25, DevTools NONE, docs-tools NONE. **The two
registers that carry `DW` rows AGREE**, and the other two carry no rows at all. ⭐ The real hazard is
sharper than disagreement: **the highest-numbered mention in a WELL-MAINTAINED register is usually
the one that has NOT been issued.** In SX_DW's own register `DW-026` appears exactly twice, as a
padding example (*"canonical form is three digits"*) and as a prohibition (*"do not mint DW-026
until the hub edit lands"*) — so a text scan emits `DW-027` and permanently burns the very id the
register is protecting. **Correct documentation makes a text scan maximally wrong**, and a resolver
that SKIPS an id is worse than one that refuses, because the gap is invisible and permanent. **ASK
THE NUMBER SERIES TABLE, NOT THE ROW COUNT** (SXC, correcting my two-rule form, which deadlocked):
*the Number Series table is the authority for what a register MAY mint; the Delivery Index is the
authority for what it HAS minted.* Zero rows is ambiguous only if you ask the second question alone,
which is what made DevTools and a brand-new series look identical — and "refuse on zero rows" made
the legitimate FIRST MINT impossible forever, since creating `XYZ-001` requires the resolver that is
refusing. Four states: declared and ≥1 row → derive from rows; declared and 0 rows → **SEED the
first id, this is a seed not an absence**; `transferred` → refuse, Owner names where to ask; **not
declared at all** (prose citation only) → refuse, which is DevTools citing `DW`. Measured:
`lastNumber` today returns **0** for an undeclared row-less prefix, so a naive resolver emits
`XYZ-1` out of nothing — the opposite defect, and live. ⭐ **This is why the Prefix cell must be the
backticked PATTERN**: seeding needs the WIDTH and there are no rows to infer it from, so padding
stops being inferred and becomes DECLARED, retiring the `DW-26`/`DW-026` class at the root rather
than at the counter. ⚠️ **The pattern must declare a MINIMUM width, not an exact one** — measured:
SX_Coder's `VS` rows span two widths (120 at two digits, 328 at three), so `VS-NNN` would contradict
120 live rows while `VS-NN` is true of all 448. That matches `padId`, which is `padStart` and
already means at-least. **THE MINIMUM DECLARES; THE LINT MUST BE EXACT** (SXC): read literally, *at
least N digits* also permits OVER-padding, so a minimum of 2 accepts `VS-26` AND `VS-026` — two
legal spellings of one number, which IS the defect class rather than a milder cousin of it.
`019`-vs-`19` is the under-padded half; the class is *more than one rendering of the same number*,
and a grep for either misses the other. So:
`canonical(prefix, n, min) = prefix + String(n).padStart(min)`, and a row is legal **iff spelled
exactly that way** — ONE SPELLING PER ID. That fails `VS-026` and `DW-26` from a single rule. ✅
**MEASURED GREEN BEFORE ADOPTION: 0 not exactly canonical across all six registers** (docs-tools 31,
AIR 35, DevTools 82, HDCT 14, SX_DW 25, SX_Coder 555). ⚠️ The first version of this measurement was
