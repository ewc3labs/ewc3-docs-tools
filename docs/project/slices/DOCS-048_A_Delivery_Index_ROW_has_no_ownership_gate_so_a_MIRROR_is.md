the same one-bit-carrying-three-states shape as the silent-marker direction above. **A check that
reports a network failure as a data defect trains people to ignore it**, which is how the
`deploy_drift.py` crash got rendered as prod drift with break-glass offered as the remedy. Cheap to
write now, expensive after someone has learned to skip the warning. ⚠️ And the blocker is worth more
than the rule it blocked: **ownership machine-readable in 2 of 6 registers** is the finding, because
HDCTranslators has no owner column at all and no parser change recovers a column that does not

two live cases: `DW-024` in SX_Coder is a ROW (mirror, global) while HDCTranslators cites `FIX-105`
in PROSE (a citation, and citations may name anything). **Mirrors are rows; citations are prose;
they are different objects.** So the rule survives scoped to global prefixes, and the Scope column
of `DOCS-049` is what tells the two apart — the table SXC specced in the same message unblocks the
rule they buried in it
