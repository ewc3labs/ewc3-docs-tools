EWC3 Labs documentation tools

  ewc3-docs format [--check] [files...]   Wrap prose so a source line is as wide as it renders.
                                          Long URLs move to reference definitions; short relative
                                          links stay inline. Never changes a word.

  ewc3-docs links                         Check every relative link resolves, with the case it was
                                          written in, that every [text][label] has a definition,
                                          and that no document is unreachable.

  ewc3-docs values [--check]              Refresh computed numbers written between
                                          <!--ewc3:name-->value<!--/ewc3:name--> markers.

  ewc3-docs series                        Who owns which ID prefix, and the last number used.
                                          Fails on an undeclared prefix, or on two roadmaps
                                          claiming the same global one. FIX is repo-local.

  ewc3-docs fix                           Values then format, in write mode. The button to press
                                          before you commit. Idempotent - running it when nothing
                                          changed costs a second and reports zero.

  ewc3-docs check                         All of the above in check mode. This is the CI command.

Configuration: .ewc3-docs.json in the repository root, or config/ewc3-docs.json, or --config
<path>. All fields optional. Two config files is an error, not a preference.

  {
    "include": ["README.md", "docs/**.md"],
    "exclude": ["docs/Config_Reference.md"],
    "format": { "width": 100 },
    "links":  { "orphanRoot": "docs" },
    "values": {
      "tests":    { "countMatches": { "files": ["test/*.ts"], "pattern": "^\s*(test|it)\(" } },
      "version":  { "fromJson":     { "file": "package.json", "path": "version" } },
      "commands": { "countJson":    { "file": "package.json", "path": "contributes.commands" } }
    }
  }
