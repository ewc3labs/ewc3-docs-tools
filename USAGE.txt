EWC3 Labs documentation tools

  ewc3-docs format [--check] [files...]   Wrap prose so a source line is as wide as it renders.
                                          Long URLs move to reference definitions; short relative
                                          links stay inline. Never changes a word.

  ewc3-docs links                         Check every relative link resolves, with the case it was
                                          written in, that every [text][label] has a definition,
                                          and that no document is unreachable.

  ewc3-docs values [--check]              Refresh computed numbers written between
                                          <!--ewc3:name-->value<!--/ewc3:name--> markers.

  ewc3-docs series                        Who owns which ID prefix, and the last number used.
                                          Fails on an undeclared prefix, or on two roadmaps
                                          claiming the same global one. FIX is repo-local.

  ewc3-docs migrate-project               Emit a migrated planning surface into docs/project_v2/,
    [--repo <dir>]                        leaving the live docs/project/ untouched so the two can
    [--owner <name>]                      be diffed and swapped in one commit at the end.
    [--write]                             Reshapes the ID register into the ownership table; where
                                          a roadmap has no register at all, synthesises one from
                                          the IDs already in use. A GLOBAL prefix is left
                                          unclaimed - a repo cannot award itself a series another
                                          register may own. Dry run without --write. Idempotent;
                                          to abandon it, delete the folder.
                                          Inventories every existing slice document first: kept
                                          if its frontmatter is usable, else backed up verbatim
                                          to slices/_legacy/ and linked. Two documents for one
                                          slice refuse the run. VS-4 and VS-004 are one slice.

  ewc3-docs index                         Regenerate the Delivery Index from the slice
    [--repo <dir>]                        documents that declare its rows. The slice document
    [--slices <dir>]                      is the authority; the table is a projection of it.
    [--write]                             Renders rows and refuses everything else: a document
                                          claiming an unminted ID is reported, never added; a
                                          row nothing claims is left alone; a row with more
                                          cells than its header has columns is refused, because
                                          no tool can tell a literal pipe from a lost column.
                                          Reads docs/project/slices/, else docs/project_v2/
                                          slices/. Dry run without --write.
    [--check]                             Fail if any row differs from what its document
                                          renders, or a row and a document do not pair up.
                                          Writes nothing; the CI command for an adopted
                                          register. --write refuses a row edited by hand
                                          since it was last committed or written - edit the
                                          slice document instead.

  ewc3-docs fold                          Fold git trailers into slice state. A commit carries
    [--write | --check]                   Slice: <ID> and State: <word> in its last paragraph;
    [--since <rev>]                       the newest per slice becomes its frontmatter state, in
                                          the register's legend spelling, and the rows follow.
                                          state_source: human is never overwritten. --check fails
                                          when a state is behind its trailer; malformed trailers
                                          after --since are errors. Dry run without --write.
    [--check-message <file> [--staged]]   Check a commit message BEFORE committing, by the same
                                          grammar: every Slice: names a document, every State:
                                          is a legend word. --staged: every staged slice document
                                          is named, and a changed state carries its State:.
                                          No-Slice: <reason> exempts naming. For commit-msg hooks.

  ewc3-docs slice new <PREFIX> "<title>"   Mint a slice in an adopted repository: the next id (past
    [--state <state>]                     every row, slice document, archived document and Last
    [--set <column>=<value>]...           Used), its slice document, and its row in the table that
    [--table "<heading>"]                 already holds the prefix (--table for a first row).
    [--write]                             Refreshes values. Refuses a frozen, cited-only or
                                          undeclared prefix. Dry run without --write.

  ewc3-docs tables                        Table rows whose cell count does not match their header -
                                          almost always a pipe inside a cell that needs escaping
                                          as |. Reports; never rewrites, because a bare pipe is
                                          ambiguous between a literal and a forgotten column.

  ewc3-docs fix                           Values then format, in write mode. The button to press
                                          before you commit. Idempotent - running it when nothing
                                          changed costs a second and reports zero.

  ewc3-docs check                         All of the above in check mode. This is the CI command.

Every command takes --repo <dir> to run against another repository (default: the current
directory), and reads that repository's config. Every command answers --help (or -h) with its usage
and runs nothing.

Configuration: .ewc3-docs.json in the repository root, or config/ewc3-docs.json, or --config
<path>. All fields optional. Two config files is an error, not a preference.

  {
    "include": ["README.md", "docs/**.md"],
    "exclude": ["docs/Config_Reference.md"],
    "format": { "width": 100 },
    "links":  { "orphanRoot": "docs" },
    "values": {
      "tests":    { "countMatches": { "files": ["test/*.ts"], "pattern": "^\s*(test|it)\(" } },
      "version":  { "fromJson":     { "file": "package.json", "path": "version" } },
      "commands": { "countJson":    { "file": "package.json", "path": "contributes.commands" } }
    }
  }
